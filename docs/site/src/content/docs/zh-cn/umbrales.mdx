## 看什么

- 在 `tool.risk` 中，先满足的阈值生效，且 `deny` 排在 `ask` 之前。只要**一个**风险就足以决定：只调高一个，看判定如何变化。
- 在 `agent.wakeup` 中区间是左闭右开的：概率等于阈值时落入上面一档。把两个值都设为 0.30：它就不再休眠了。
- 模型从头到尾没有变化。变的是你的策略，以及有多少决策会交给人。

自带流程的数值（0.55 和 0.85；0.3 和 0.5）只是初步估计。想用你自己的数据固定它们，请看[决策指南](/zh-cn/guia-decisiones/)和[练习](/zh-cn/ejercicios/)。
