## 本地代理

Jevalan 在本机提供 HTTP 守护进程。智能体调用 Jevalan，而不是直接连接后端。代理可以添加已配置的密钥，并转发 System One 请求。

## 三种决策路由

| 路由 | 用途 |
|---|---|
| `POST /v1/systemone` | 将 System One 请求发送到默认后端。 |
| `POST /v1/decide/{flow}` | 按名称运行 YAML 流程。 |
| `POST /v1/hub` | 解析类型化能力，例如 `tool.risk`。 |

流程和能力从工作目录加载，可在 TUI 中查看。`/events` 路由向界面发布事件。

## 谁来执行操作

Jevalan 返回响应或决策。它不会执行请求的操作、修改智能体文件，也不会代替智能体批准操作。责任仍由客户端承担。

## 后端和服务商

流程可以使用本地规则、查询兼容后端，或请求已配置的服务商作出决策。能力中心也可以使用 `flow`、`http` 或 `exec` 服务商；默认禁用进程执行。
