## 本地决策入口

Jevalan 与你的工具一起运行。它集中管理对模型和本地策略的访问，并通过终端界面观察流量。

<CardGrid>
  <Card title="兼容代理">
    将 System One 请求转发到你配置的后端，同时保留智能体与服务之间的接口约定。
  </Card>
  <Card title="类型化流程">
    使用 YAML 定义决策，组合规则与问题，并为结果和错误声明路由。
  </Card>
  <Card title="能力中心">
    通过本地 API 暴露可复用的决策能力，例如 `agent.wakeup` 或 `tool.risk`。
  </Card>
</CardGrid>

## 工作方式

```text
智能体 → 本地 Jevalan → 后端或流程 → 类型化响应 → 智能体
```

Jevalan 不会执行命令，也不会应用更改。它只返回决策；后续操作仍由智能体控制。

## 试用演示

演示使用模拟服务和可重复的流量，不需要密钥，也不会调用外部服务商：

```sh
jevalan tui --demo
```
